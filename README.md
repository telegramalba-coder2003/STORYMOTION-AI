# STORYMOTION AI — version mobile

Cette première version est une application web progressive (PWA) de démonstration, adaptée aux téléphones Android.
Elle permet de saisir des histoires, préparer des personnages et organiser des scènes. Les données sont enregistrées localement dans le navigateur du téléphone.

## Utilisation
- Décompresser le dossier.
- Héberger les fichiers sur un service web statique HTTPS (par exemple GitHub Pages).
- Ouvrir l'adresse publiée dans Chrome sur Android.
- Dans le menu Chrome, choisir « Ajouter à l'écran d'accueil » ou « Installer l'application » si l'option est proposée.

## Limites
Ce prototype ne génère pas encore de vraies images 3D, de voix off ni de vidéos. Ces fonctions demanderont des services IA connectés et un serveur sécurisé. Ne pas saisir d'informations personnelles sensibles dans cette version de démonstration.
